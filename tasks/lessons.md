# 교훈

- 사용자가 기존에 연결한 사이트를 언급하면 현재 작업 폴더에 없다는 이유만으로 재연결을 요청하지 않는다. 등록 프로젝트, 이전 작업 기록, 로컬 저장소와 원격 최신 상태를 먼저 확인한다.
- 오래된 로컬 포트폴리오 사본과 운영 저장소를 구분하고, 최신 원격 변경과 사용자 편집을 보존한 뒤 수정한다.

- 사용자가 논문의 발표 월을 정정하면 원본 JSON과 CV 문서에 함께 반영하고, 월 단위 최신순 정렬 결과까지 확인한다. 연도만 기록된 값을 최신성의 완전한 근거로 취급하지 않는다.

- CV의 PC 여백 개선을 대시보드식 다중 열 구성으로 해석하지 않는다. 실제 학술 CV는 단일 문서 흐름과 간결한 서지 정보가 우선이며, 출판 실적과 심사 중 원고를 분리한다.

- 사용자가 활동 기간을 특정 연도까지로 정정하면 해당 종료 연도를 명시한다. 이를 Present로 확대 해석하지 않고 JSON과 관련 CV 문서를 함께 갱신한다.

- 공개 화면에서 제외한 항목을 원본 데이터 전체 직렬화로 챗봇에 다시 노출하지 않는다. 공개 레코드 선택 규칙과 표시 필드 목록을 컨텍스트·링크 검증에 함께 적용하고, 과거 답변이 새 공개 근거로 재유입되지 않도록 컨텍스트 버전을 확인한다.

- 제외된 논문은 논문 목록뿐 아니라 소개문·Research 설명에 남은 짧은 제목과 연구 고유 내용도 점검한다. 긴 정식 제목 제외 테스트만으로 재노출 방지를 주장하지 않는다. 사용자에게서 보고된 정확한 질문으로 실제 답변을 검증한다.

- 컨텍스트에서 제목을 지웠어도 모델은 제목을 일반 연구 철학으로 재해석할 수 있다. 정확한 사용자 질문을 운영 모델에 실행하고, 미표시 고유명사의 비유적 연결도 검증 실패로 다룬다.

- OAuth 소개/정책의 독립 공개 페이지를 추가할 때 포트폴리오 내비게이션과 챗봇 컨텍스트에 자동 편입하지 않는다. 직접 URL 접근, 검색 제외, 기존 메뉴 링크 부재와 컨텍스트/답변 링크 제외를 함께 검증한다.
